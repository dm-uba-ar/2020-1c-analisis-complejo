### Régimen de aprobación

Se deben aprobar dos exámenes parciales o un prefinal (presenciales), o sus respectivos recuperatorios, lo cual todavía no está determinado. Para poder ser incluido en las actas de trabajos prácticos es necesario haberse inscripto, mediante el [sistema de inscripciones de la facultad](https://inscripciones.exactas.uba.ar/exactas/)
